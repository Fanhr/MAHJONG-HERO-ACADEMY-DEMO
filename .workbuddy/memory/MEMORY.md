# 英雄麻将 · 项目长期记忆

## 游戏定位（《开战！麻神力攻学院！》）
- 英雄技能 × 竞技麻将，1v1v1v1 血量攻防回合制竞技，PC 平台；目标用户：自走棋/炉石/卡牌构筑/竞技麻将等策略玩家。
- **与传统麻将的三大差异（所有宣传/介绍材料的统一叙事框架）**：
  1. 英雄技能——解耦地区玩法，不同流派麻将同桌对局，技能反向改写做牌决策；
  2. 技能卡系统——加速构筑、加深博弈（五系 20 张：谋/战/御/运/生，行动点 1-4）；
  3. 胡牌≠游戏结束——可无限次数和牌，血量归零才分胜负。
- 伤害规则（准确口径）：番数=伤害（指数曲线）；自摸=对全场群体伤害；荣和（点炮胡）=胡牌者对点炮者单体伤害。
- 四位英雄：小夭（定缺·杠）、汐金（金牌·百搭，三金倒/抢金）、咯哒（捉鸡·冲锋鸡）、澪（立直·役，亮剑/秋后算账）。
- 世界观：麻神力攻学院，雀士以「雀技」争夺「雀神之战」冠军，获「雀神」称号；青春热血二游群像。

## 宣传文案规范（用户明确要求）
- 不直接提及具体地域（川麻/闽南/贵州/日麻等），以机制词暗示：杠即时伤害、定缺、捉鸡、立直、金牌等。
- 禁止"点炮反伤"等与设计相反的表述；点炮伤害=胡牌者对点炮者的单体伤害。
