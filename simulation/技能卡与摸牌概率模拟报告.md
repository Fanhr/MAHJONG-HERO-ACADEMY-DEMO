# 技能卡与摸牌概率模拟报告

> 数据来源：基于《局内游戏流程.md》规则文档进行的理论概率建模与组合计数计算（非蒙特卡洛随机模拟，为解析法精确计算/枚举验证）。

## 一、麻将牌摸牌累积概率（超几何分布模型）

### 1.1 参数设定
- 牌墙总数：136张（不含花牌）
- 4人局起手发牌后剩余可摸牌数：N = 84
- 每回合每人摸1张，4人轮转，起家（p=0）单局最多摸 21 回合

### 1.2 口径A：目标为某一种牌面（k=4，如"5万"共4张任意1张）

| 回合数 r | 已摸牌数 M | 累积概率 P(命中≤r) |
|---|---|---|
| 1 | 1 | 4.76% |
| 3 | 9 | 37.4% |
| 5 | 17 | 60.6% |
| 10 | 37 | 89.5% |
| 15 | 57 | 98.1% |
| 21 | 81 | 99.998% |

公式：P(命中≤r) = 1 − ∏(i=0→k-1) (N−M−i)/(N−i)，其中 M = 4(r−1)+p+1

### 1.3 口径B：目标为唯一1张指定实体牌（k=1）

| 回合数 r | 已摸牌数 M | 累积概率 P(命中≤r) |
|---|---|---|
| 1 | 1 | 1.19% |
| 5 | 17 | 20.2% |
| 10 | 37 | 44.0% |
| 21 | 81 | 96.4% |

公式：P(命中≤r) = M / N（k=1时的简化形式）

### 1.4 关键假设
- 洗牌充分随机，目标牌在牌墙各位置等概率分布
- 未计入杠尾补牌、效果摸切、副露打断对实际回合节奏与牌墙消耗速度的影响（均会使实际荒牌提前、可摸回合数减少）
- p为该玩家在全局摸牌顺序中的位置偏移（起家p=0最有利）

## 二、技能卡抽卡累积概率与期望（分支1：候选命中口径）

### 2.1 参数设定
- 私有技能卡池：N = 20张（基础版本，每种各1份，忽略冷却区动态占用）
- 目标技能卡：k = 1张
- 每回合抽卡阶段：从N张中抽3张候选（不放回抽取，候选间不重复）
- 口径：只要目标卡出现在本回合3张候选中即算"命中"，不考虑玩家是否实际选中它

### 2.2 单回合命中概率

P(命中) = C(1,1)×C(19,2) / C(20,3) = 171/1140 = 3/20 = 15%

### 2.3 累积概率分布

各回合独立同分布，P(累积命中≤r) = 1 − 0.85^r

| 回合数 r | 累积概率 P(命中≤r) |
|---|---|
| 1 | 15.0% |
| 2 | 27.75% |
| 3 | 38.59% |
| 5 | 55.63% |
| 8 | 72.76% |
| 10 | 80.36% |
| 15 | 90.79% |
| 20 | 96.09% |
| 30 | 99.29% |

### 2.4 期望摸到次数

- 整局期望命中次数（按单玩家约21回合估算）：E[X] = r × p = 21 × 0.15 = **3.15 次**
- 期望首次命中所需回合数（几何分布）：E[T] = 1/p = 1/0.15 ≈ **6.67 回合**

### 2.5 关键假设与偏差来源
- 假设该玩家能打满约21个理想回合，未计入被淘汰、副露跳过回合、杠加速荒牌等因素（实际r通常更低，期望命中次数会相应下降）
- 未考虑冷却区占用导致池内实际可抽张数周期性小于20的情况
- 未考虑"重抽"机制额外增加的同回合内试验次数

## 三、技能卡构筑组合数计算（张数分配 + 分堆形状）

### 3.1 约束条件
- 入场20张技能卡，AP消耗总和 ≤ 50点
- AP消耗≥3的技能卡，同名至多2张
- AP消耗<3的技能卡，同名至多4张
- 假设AP消耗档位为1/2/3/4/5，各档位不同名字种类数视为充足（不构成计数瓶颈），只统计"张数分配方案"与"同档位内部分堆形状"，不区分具体是哪个名字

### 3.2 第一层：张数分配方案数

设 n1..n5 为AP=1~5各用的张数，约束：
- n1+n2+n3+n4+n5 = 20
- n1+2n2+3n3+4n4+5n5 ≤ 50（化简为 n2+2n3+3n4+4n5 ≤ 30）

枚举结果：**2535 组**可行张数分配

### 3.3 第二层：同档位内部分堆形状（整数分拆数）

- <3AP档位（AP1、AP2）：分拆数上限每堆≤4，记 p≤4(n)
- ≥3AP档位（AP3、AP4、AP5）：分拆数上限每堆≤2，记 p≤2(n)

部分数值参考：

| n | p≤4(n) | p≤2(n) |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 1 | 1 |
| 4 | 5 | 3 |
| 8 | 15 | 5 |
| 12 | 34 | 7 |
| 20 | 108 | 11 |

### 3.4 最终结果

对每组张数分配 (n1,n2,n3,n4,n5)，方式数 = p≤4(n1) × p≤4(n2) × p≤2(n3) × p≤2(n4) × p≤2(n5)，对全部2535组求和：

**最终组成方式总数 = 845,469 种**

### 3.5 关键假设
- 每个AP档位下的可选技能卡"名字"种类数被假设为无限/充足，不构成瓶颈，只统计张数与分堆形状，不区分具体名字
- 若后续该假设不成立（即某档位实际种类数有限），需改用有界多重集组合数（生成函数展开）重新计算，结果会小于本报告数值

## 四、复核用计算脚本（Python，可直接运行验证）

```python
def partitions_le_m(n, m):
    dp = [0] * (n + 1)
    dp[0] = 1
    for part in range(1, m + 1):
        for s in range(part, n + 1):
            dp[s] += dp[s - part]
    return dp[n]

max_n = 20
p_le4 = [partitions_le_m(n, 4) for n in range(max_n + 1)]
p_le2 = [partitions_le_m(n, 2) for n in range(max_n + 1)]

total = 0
cnt_groups = 0
for n5 in range(21):
    for n4 in range(21 - n5):
        for n3 in range(21 - n5 - n4):
            for n2 in range(21 - n5 - n4 - n3):
                n1 = 20 - n2 - n3 - n4 - n5
                if n1 < 0:
                    continue
                if n2 + 2 * n3 + 3 * n4 + 4 * n5 <= 30:
                    cnt_groups += 1
                    total += p_le4[n1] * p_le4[n2] * p_le2[n3] * p_le2[n4] * p_le2[n5]

print("可行张数分配组数:", cnt_groups)   # 2535
print("最终组成方式总数:", total)        # 845469
```
